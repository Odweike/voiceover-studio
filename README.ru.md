Небольшое нативное приложение для записи озвучки по сценарию. Откройте текст, запишите отдельные реплики, сравните дубли и перенесите выбранные WAV-файлы в видеоредактор.

Делал для собственного рабочего процесса, потом решил поделиться. Приложение бесплатное, работает без интернета и не требует аккаунта.

## Скачать и установить

**[Voiceover Studio 0.3.0 — универсальный DMG](https://github.com/Odweike/voiceover-studio/releases/download/v0.3.0/Voiceover-Studio-0.3.0-universal.dmg)**

Нужна **macOS 14.4 или новее**. Включены сборки для Apple Silicon и Intel. Проверено на Apple Silicon; на физическом Intel Mac этот выпуск пока не тестировался. Интерфейс приложения — на русском.

1. Откройте DMG и перетащите **Voiceover Studio** в **Applications («Программы»)**.
2. Извлеките образ и запустите приложение из «Программ».
3. Разрешите доступ к микрофону при первой записи.

**При первом запуске:** у этой независимой версии нет нотарификации Apple; используется локальная подпись. macOS может заблокировать запуск. Если вы доверяете загрузке, после попытки запуска откройте **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**. [Официальная инструкция Apple](https://support.apple.com/102445).

Скачивайте приложение из [Releases этого репозитория](https://github.com/Odweike/voiceover-studio/releases). Рядом с DMG опубликована [контрольная сумма SHA-256](https://github.com/Odweike/voiceover-studio/releases/download/v0.3.0/SHA256SUMS.txt). Для использования не нужны Xcode, Python или Node.js.

## Что умеет

- **Сценарий рядом с записью.** Русский и английский текст в таблице с изменяемой шириной столбцов. Можно использовать один язык.
- **Запись по репликам.** Озвучивайте блок целиком или делите его маркерами `[voice:...]`.
- **Несколько дублей.** Прослушивание, пауза, выбор лучшего и перемещение ненужных записей в Корзину.
- **WAV для монтажа.** Моно, 48 кГц, 24-битный PCM.
- **Отдельные проекты.** Каждый импорт создаёт свою папку; дубли разных сценариев не смешиваются.
- **Локальное хранение.** Обычные JSON и WAV, безопасное сохранение метаданных и журнал незавершённой записи.

Это рекордер для конкретной задачи, а не полноценный аудиоредактор. Обрезку, обработку звука и монтаж выполняйте в привычном редакторе. Автоматической синхронизации с Premiere и записи изменений обратно в Excel нет.

## Первая озвучка

При первом запуске приложение создаст небольшой пример.

1. Нажмите **Импорт сценария**, чтобы открыть JSON или XLSX. Для продолжения работы нажмите **Открыть проект** и выберите его папку.
2. Нажмите **Записать эту реплику**, затем **Сохранить**. Для ещё одной попытки используйте **Новый дубль**.
3. Прослушайте записи и выберите лучшую. Первый дубль выбирается автоматически.
4. Нажмите **Показать проект**: откроется папка с WAV-файлами и `manifest.json`.

Импорт всегда создаёт **новый проект**. Чтобы продолжить прежний сценарий с его дублями, открывайте папку проекта, а не импортируйте таблицу повторно.

## Как подготовить сценарий

Возьмите [готовый пример JSON](Resources/scenario.json). У каждого блока должны быть уникальный `id`, отображаемый `number` и оба языковых поля; одно из них можно оставить пустым:

```json
[
  {
    "id": "intro",
    "number": "1",
    "russian": "Привет! Сегодня покажу, как это работает.",
    "english": "Hello! Today I'll show you how this works."
  }
]
```

Для XLSX используйте простую однолистовую таблицу: **заголовки в строке 1, русский текст в D, английский — в E**. Номер блока — в A. Формулы не вычисляются.

Чтобы записывать части блока отдельно, поставьте маркер перед каждой репликой:

```text
[voice:intro-greeting]
Привет!

[voice:intro-start]
Давайте начнём.
```

Маркеры должны быть уникальны во всём сценарии. Если присутствуют оба языка, используйте одинаковые маркеры в одинаковом порядке. [Полный формат сценария и ограничения импорта](docs/SCRIPT_FORMAT.md).

## Где мои записи

По умолчанию проекты лежат в `~/Movies/Voiceover Studio/Projects/`. В каждой папке — сценарий, manifest и каталог `Recordings`. Для резервной копии сохраняйте **папку целиком**, чтобы не потерять связь реплик и дублей.

В приложении нет сетевых сервисов, аналитики, регистрации и облачной загрузки. Журнал помогает восстановить запись, если приложение закрылось до сохранения метаданных. После сбоя проверьте восстановленное аудио: сохранность файла не гарантирует корректность WAV, прерванного во время записи.

Проекты из исходной личной версии можно открывать на прежнем месте. Сначала закройте старое приложение. [Устройство хранения и восстановление](docs/ARCHITECTURE.md).

## Сборка из исходников

Нужны macOS 14.4+ и Swift 6+. Для обычной сборки достаточно Xcode Command Line Tools, для универсального DMG нужен полный Xcode.

```sh
git clone https://github.com/Odweike/voiceover-studio.git
cd voiceover-studio
./build.sh
open "build/Voiceover Studio.app"
```

Запускайте именно `.app`, а не `swift run`: так macOS прочитает описание разрешения на микрофон и встроенный пример.

```sh
swift test                     # проверки поведения
python3 tools/check.py         # проверка собранного приложения
./tools/package-dmg.sh         # универсальная сборка, DMG и SHA-256
```

SwiftUI, AVFoundation и Foundation. Сторонних зависимостей для работы приложения нет.
